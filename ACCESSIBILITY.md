# Accessibility statement

We want heb-google-cal to be usable by everyone. Our target is WCAG 2.2 level AA for
user-facing content and interfaces.

## What we do

- Semantic markup and keyboard-navigable interfaces.
- Readable contrast and scalable text.
- The project ships a web UI. CI runs automated JavaScript regression tests; accessibility checks are manual today (semantic markup, keyboard navigation, contrast), reviewed on desktop and mobile.

## Known limitations

Accessibility work is ongoing. If something blocks you, we want to know.

## Feedback

Report an accessibility problem by opening an issue:
https://github.com/reihlinstinct/heb-google-cal/issues/new/choose
If the report is sensitive, use a private security advisory instead:
https://github.com/reihlinstinct/heb-google-cal/security/advisories/new
